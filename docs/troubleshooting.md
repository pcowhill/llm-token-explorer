# Troubleshooting browser inference

| Symptom                                                  | Likely cause                                                                                                     | What to do                                                                                                                              |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| “WebGPU unavailable”                                     | Browser without WebGPU, disabled flag, blocklisted GPU, or non-secure context                                    | Use WASM / CPU (works everywhere). Chrome/Edge ≥ 113 on Windows/macOS/ChromeOS support WebGPU; Linux and Firefox/Safari support varies. |
| “requires f16 but the device does not support it”        | fp16 / q4f16 on a GPU without `shader-f16`                                                                       | Choose q8/fp32/bnb4, or WASM. The app pre-selects a compatible variant.                                                                 |
| “… returned invalid next-token logits”                   | The variant produced NaN / constant (e.g. all-zero) logits on this backend — a broken export or an fp16 overflow | Choose another quantization or backend. Please report the model, dtype and backend.                                                     |
| Qwen3.5: “Needs WebGPU”                                  | None of its exports runs on WASM                                                                                 | Switch the backend to WebGPU (needs a GPU), or use **Tokenizer only**.                                                                  |
| Hugging Face repo: “not found”, “gated”, “No ONNX files” | Typo, private/gated repo, or not a Transformers.js export                                                        | Check the id and revision; look for an `onnx-community` export.                                                                         |
| `std::bad_alloc`, “out of memory”, tab crash             | Model too large for WASM's 4 GB address space or the device                                                      | Use a smaller model or a 4-bit variant; close other tabs.                                                                               |
| “Failed to fetch”                                        | Network problem, blocked huggingface.co, or interrupted download                                                 | Retry; completed files are cached. Corporate proxies may block `huggingface.co` or its CDN.                                             |
| “You are offline and … is not in the browser cache”      | Model never fully downloaded                                                                                     | Load it once online, or use Local files.                                                                                                |
| Model downloads again every visit                        | Private window, storage cleared/evicted, or quota exceeded (a warning is shown)                                  | Use a normal window; **Model → Cache → Request persistent storage**.                                                                    |
| Slow inference on CPU                                    | Single-threaded WASM (no cross-origin isolation on GitHub Pages), large vocabulary                               | Use WebGPU if available; prefer SmolLM2; enable the KV cache in Diagnostics for faster generation (see the exactness caveat).           |
| Text box is read-only with a warning                     | The token sequence cannot be reproduced by re-tokenizing its text (special tokens, manual IDs)                   | Edit at token level, or click _Edit as text anyway_ to re-tokenize.                                                                     |
| Imported experiment shows red tokens                     | Token IDs outside the loaded model's range                                                                       | Load the model the experiment was created with.                                                                                         |
| Different results than another device                    | Backend/precision differences change logits                                                                      | Expected; compare with the same backend and dtype.                                                                                      |
| Local model: “Missing required file”                     | Incomplete selection                                                                                             | Select the whole folder, including `tokenizer.json`, `tokenizer_config.json` and any `*.onnx_data` files.                               |
| Local model: unsupported architecture                    | Not a decoder-only causal LM supported by Transformers.js                                                        | Use an `onnx-community` text-generation export.                                                                                         |

Debugging aids: append `?debug=1` to the URL to expose a read-only `window.__lte` handle
to the workbench state in the developer console; the Diagnostics panel shows timing,
tensor shapes, cache state and library versions.
